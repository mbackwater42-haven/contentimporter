# Roadmap: (contentimporter)

## Phase 1 — v1.0 (done)
- Target: Develop module for Foundry VTT v14 build 364, per official docs, to import
  selected content.
- Deliverables:
  - Art Browser: folder-tree image browser with collapsible/state-persisted folders,
    three drag modes (plain Token with no Actor, Alt+drag art-only Tile, Ctrl+drag
    Actor-backed Token created flat at the Actors sidebar root).
  - Compendium Import: header button on any Actor sheet (system-agnostic) to search
    every Actor compendium in the world and overwrite name/stats/items/effects on the
    current Actor, keeping its existing token art.

## Phase 2 (not started)
- Target: expand content import to other media
- Deliverables: add features for importing audio, text, animations, and other content
